# 共同作業後の自由交流：実行前計画

人の観察記録はまだない（ユーザー確認済み）。本実験は仮定の感度分析であり、人間の効果や4要因条件の実証とは区別する。人の4条件比較は別文書の実施計画・記録票を準備する。

## 固定条件

4人、全6既知ペア、seed 101–1100。A/Bの既知関係定義を維持。
前回の強条件の48ターンを再現し、24ターンの自由交流を追加する。計72会話。前半の全接触・話題・反応・関係状態は通常共同作業と一致させる。情報状態は初めて条件（各自1情報）を用い、話題への接続は無効のまま。
後半は通常の話し手順序、相手選択、話題、反応式、関係閾値を使用し、相手選択の重みだけに下記の仮定を適用する。後半の接触・話題・反応確率は固定しない。滞在・離脱モデルは追加しない。

## 3つの仮定

共同作業中、iがjから受け取った情報数をc(i,j)とし、自由交流の選択重みを

`既存の重み × 2 ** (theta × c(i,j) / 3)`

とする。theta=-1,0,+1。最大で半分/不変/2倍になるが、これは選択確率がそのまま半分/2倍になる意味ではない。全候補の重みを正規化して選ぶ。
情報交換履歴は共同作業終了時に固定する。新しい関係加点や好反応加点は与えない。既知ペアやBridge候補を優先しない。実測値ではなく対称な感度分析用設定。
全候補が同じだけ情報を提供していれば倍率が相殺され、選択確率は変わらない。これも正しい結果として扱う。

## 指標

48/72ターンのBridge成立数・率、自由交流中の追加成立数、未成立ターン平均、全4本成立率、自由交流の既知ペア/Bridge候補への会話割合。
情報提供者への接触割合、選択相手からの受領情報数/3の平均、同一状態での選択重み変更による期待情報履歴量の変化を補助指標とする。全6ペアは前半に接触済みなので、後半は全て再接触である。
theta=0を基準にA/B別の対応差とB-Aの変化を出す。6ペアをseed内で平均してからMonte Carlo区間を算出。主指標のペア別比較は6ペア×2方向×2条件=24比較の補正区間も保存する。新しいseedでの予測検証ではない。

## 検証

前半48ターン完全一致、theta=0の通常ルール互換、情報のない対照では全theta一致、候補ごとの重み・選択確率・乱数による選択、既存式による反応、全ターン関係再構築、保存後表照合、ソース/出入力ハッシュを確認する。
前半ですでにBridgeが多く成立しているため上限4本による余地の小ささを報告する。モデルに効果が出ても人間の再接触傾向を支持する証拠とはしない。
