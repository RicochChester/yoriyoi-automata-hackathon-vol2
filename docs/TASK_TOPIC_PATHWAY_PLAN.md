# 課題の題材と履歴経路の検証計画

結果を見る前の固定計画。48会話、4人、seed 101–1100、全6既知ペア、A/B。
通常共同作業の全48ターンの話し手・聞き手を再生する。人物、反応式、関係閾値、情報所有・移転は変更しない。

## 題材比較（弱・中・強）

- original: 地域、展示、ものづくり、食（前回を再現）
- rotated: ものづくり、食、地域、展示（情報IDに対応する題材を2位置ずらす）
- outside: 天文、古典、地質、法律（人物の興味登録にない題材。モデルでは意味理解でなく文字列一致の診断対照）

通常共同作業は前回保存記録を参照する。originalも再実行して前回との完全一致を検証し、即時反応の診断記録を追加する。新規題材2条件を実行する。
rotatedは題材集合を変えず割り当て依存性を見る。outsideは興味一致のない場合の境界条件であり、現実の題材の良し悪しの比較ではない。

## 履歴経路（強・originalのみ）

過去の話題を参照する経路Tと、過去の好反応を参照する経路Rを、それぞれ通常共同作業の履歴に固定する。T固定、R固定、両方固定を追加する。関係評価には常に実際に生成した会話を使う。
両方固定条件と通常共同作業の差は、後続の話題選択・反応履歴を通常に保った上で質問場面だけ変えた制御比較。
originalと両方固定の差は、この制御下での履歴波及。TとRの作用は相互作用し得るので、唯一の自然な媒介割合とは呼ばない。

全ての新規条件で、質問時の同一履歴・同一乱数の下、課題話題と自然な話題の反応を二重評価して記録する。比較用評価は乱数も世界も変えない。質問以外の反応差も別集計する。

## 指標と検証

主指標: Bridge成立数(0–4)、率、通常共同作業との差。副指標: 未成立累積ターンの4本平均、既知/Bridge会話割合、全4本成立率。質問時/非質問時の好反応数差、即時の好反応増減数を保存。
全6ペア平均はseed単位で集約し、1000 seedの対応差から既存方式の正規近似95% Monte Carlo区間を算出する。主比較の同時区間は12セル×6ペア×2条件=144比較にBonferroni補正する。区間は人間集団への信頼区間ではない。題材の網羅性や新規seedでの再確認は別問題。
再現を含む3題材×3強度 + 3履歴条件×強のみ =12セル、144,000条件実行。
介入なし互換性、前回original再現、接触・情報経路一致、全ターンの関係再構築、表と保存トレースの照合、出入力ハッシュを検証する。
公開・LLM課金・感謝/達成感の新規加点は対象外。実験モジュールを使わなければ従来動作。
