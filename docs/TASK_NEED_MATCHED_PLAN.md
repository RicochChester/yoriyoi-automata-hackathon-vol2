# 話題・反応確率を揃えた確認必要性の対照実験

実行前に固定する計画。48会話、4人、全6既知ペア、seed 101–1100、共同作業の弱/中/強。A/Bの定義は維持する。
比較は各A/B内の「慣れた」と「初めて」。AとBのオンライン関係由来の話題差まで消す操作ではない。

慣れた条件は全4情報を全員が保有。初めて条件は全員のtask_familiarity=0、各自1情報のみ保有し、残りは他者への確認で取得する。所有者と移転規則は前回のInformationStateをそのまま使う。
全48接触を通常共同作業の保存記録に揃える。既存topic_link=Falseを使い、手順確認が会話の話題を変える経路を使わない。確認要求と移転は情報ログに残す。
話題は各条件で既存ルールから計算し、反応も既存式で別々に計算する。回答や関係をコピー/強制一致させない。履歴固定は使わない。
人物、興味、shared interest、話題の興味一致、接触、話題、乱数、各ターンの反応確率分布を照合する。情報状態以外の全会話・全関係状態が一致することを受け入れ条件とする。

## 構造上の予測

現モデルの反応式・関係式は、情報保有量・確認必要性・心理的な新奇性を直接参照しない。情報状態から話題への接続を外すと、同じ初期状態・同じ乱数では、帰納的に会話と関係が一致するはずである。
差ゼロは「人間に新奇性の効果がない」の証拠ではない。モデルに残る作用経路の有無を調べる負の対照/整合性検証である。新奇性と情報依存を別要因として同定する実験でもない。

## 出力と検証

全72,000条件を実行。Bridge数/率・形成の遅れ・会話割合・全4本成立率と、確認要求数・情報移転数・手順情報充足率を保存する。
手順情報の充足率を、実作業の完成度や達成感と呼ばない。慣れた条件の初期充足率1は「課題が完了済み」という意味ではない。
差の区間が[0,0]でも、人間の効果を精密にゼロ推定できたとは解釈しない。6ペアはseed内で平均してから既存のMonte Carlo集計を行う。
元条件再現、情報移転の再構築、反応確率の独立検算、保存後読み戻しと表照合を行う。通常UI・関係閾値・感謝/達成感ボーナスは変更しない。
