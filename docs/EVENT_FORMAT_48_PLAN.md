# 48ターンのイベント形式比較：実行前計画

正本はローカルソース、event_formats_v2.json、本計画。ルール版のみ。
4人、48ターン、seed 101–1100、全6既知ペア、A/B、13条件。
156,000条件実行、936,000ペア行。既存人物・初期世界・関係閾値は維持。
1ターンは1人から1人への会話と返答・判定。介入時のみ話し手変更可。

|強度|シャッフル・紹介・話題の介入ターン|共同作業ブロック（両端含む）|
|---|---|---|
|弱|8,15,22,29,36,43|22–27|
|中|8,11,14,17,20,23,26,29,32,35,38,41|8–13,36–41|
|強|2,4,5,7,10,11,13,16,17,19,20,22,25,26,28,31,33,35,36,38,41,43,44,46|2–7,15–20,28–33,41–46|

共同作業の配置はユーザー承認済み。各6会話ブロックが全6ペアを1巡。
シャッフルも同じ順序の全6ペアを1/2/4巡し、毎巡方向を反転する。
順序・方向とホストのタイブレークはv1のseed別乱数を維持する。
施策がシミュレータの乱数列を別途消費しない。A/Bの強制計画は完全一致。
ホストは履歴上の最小会話回数ペアを選び、当該ターンのみ選択bonus=1.0。
履歴が異なればA/Bの紹介先は異なり得る。紹介は強制会話ではない。
話題提示は既存の共通興味判定だけを一時的に有効化。オンライン記憶の
話題優先や実際の興味との一致判定を変更しない。

共同作業は課題上の伝達・確認・引き継ぎを記録する。シャッフルとの差は
連続配置と発話の目的表記。新しい能力、成功判定、心理効果、報酬はない。
したがって両者の結果差は時間配置の効果として扱う。

主指標：固定4本のBridgeの顔見知り以上の成立数と成立数/4。
比較順序：B−自由交流B、A−自由交流A、B−A、差の差。
副指標：未成立累積ターン（成立ターン−1、打切り48）の4本平均、
既知ペア/Bridge会話割合（分母48）、全4本成立率。
同seed差の平均と正規近似95% Monte Carlo区間を計算。
各比較系列ごとに全6ペア×13条件=78または×12施策=72の
Bonferroni同時区間も保存。系列をまたいだ探索の全体誤差保証はしない。
全体集計は同seed内で6ペアを平均してから1000seedを集計し、
6000件を独立標本とは扱わない。率の差と区間は件数差/4。

共同作業の成立時期を開始前・作業中・ブロック間・最終作業後で分離。
最終作業後の観察期間は弱21・中7・強2ターンで異なる。
これらは記述指標で、作業が後の成立を引き起こした証拠ではない。
人物別の話し手回数、介入前接触2回未満の強制ペア率、紹介実現率、
介入中の初回Bridge会話と成立数も記録。

品質ゲート：v1保存結果との一致、指定配置/均等性/一時作用のテスト、
小規模全条件実行、48ターン自由交流の既存6000 A/B記録との一致、
全会話から関係状態の再計算、全CSVと集計の再計算、入出力ハッシュ。
既存データは上書きしない。新しい出力先が必要。完了manifestがない
ディレクトリは未完了である。失敗時はエラーと当該pair/seedを調べる。
無効化は従来コマンドを使うこと。元の人物/ルール設定変更は不要。

今回の推論範囲はこの4人・ルールモデル・固定48会話である。
滞在時間の自発的延長、人間一般、共同作業の心理的効果は測定しない。
