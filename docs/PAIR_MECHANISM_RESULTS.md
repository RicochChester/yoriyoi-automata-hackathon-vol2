# 全既知ペアの作用除去・会話相手固定：結果

2026-09-11。**会話配分を変える経路の重要性が、全6ペア・全4時点で再現した。特に既知相手への選択優位を外すと差が大きく縮み、会話相手系列を固定するとBridge差は全seedでゼロになった。**

他の5ペアへ前回の機序実験を広げ、元ペアも整合性対照に含めた。4人、技術1往復の事前交流、元のルールを固定。seed101〜1100。通常と7介入の8条件を48ターンまで実行し、12・24・36・48ターン時点を観測した。

実際の条件実行96,000回、条件時点384,000件、ペア行2,304,000行。短い時点の別実行との一致を先行テストした上で、同一実行の途中を読み取った。前回と同じseedなので、新規独立追試とは呼ばない。

## 2. 改善は乱数の揺らぎと区別できるか

「介入条件のB−A」から「通常条件のB−A」を引いた値を、同じseed内で計算した。正なら通常の負の差を縮める方向。6ペア×4時点×7介入=168対比を一familyとして、Bonferroni補正の近似同時区間を用いた。

|介入|24ペア時点のうち改善方向で補正区間がゼロを跨がない数|平均差の変化の範囲|
|---|---:|---:|
|選択優位OFF|24/24|+0.066〜+0.209|
|反応優位OFF|7/24|+0.003〜+0.037|
|話題記憶OFF|0/24|−0.004〜+0.005|
|慎重免除OFF|0/24|−0.002〜+0.005|
|全作用OFF|24/24|+0.069〜+0.244|
|Aの相手系列に固定|24/24|+0.069〜+0.244|
|Bの相手系列に固定|24/24|+0.069〜+0.244|

選択優位OFFは全24点で差を縮めた。ただし「選択優位だけですべて説明できる」ではない。選択OFF後の差そのものを192条件familyの補正区間で見ると、次の6点はなお負だった。

- あかね―みどり：12・24・36ターン
- こはる―くるみ：12ターン
- くるみ―みどり：12・36ターン

反応の加点等が残ると、既知ペアで良い反応が起き、それを記憶して再び相手を選びやすくなる経路がコード上にある。元の `RuleTalkInitiator.selection_weight` は過去の肯定的反応にも選択重みを加えるためである。これは残差の説明候補であり、その経路だけを新たに除去して寄与量を測ったわけではない。

あかね―くるみ48ターンの+0.001という点推定は、促進効果の確証ではない。また、話題・慎重免除の対比区間がゼロを跨ぐことを「作用がない証明」とは扱わない。

慎重な人がいないペアでは慎重免除の除去は原理的に効かない。慎重なみどりがいる場合でも、こはるとは共通の興味があり、元ルールには共有興味による別の慎重ペナルティ免除がある。今回外すのは既知関係による免除であり、共有興味の作用まで外してはいない。

## 3. 全作用OFFと相手固定はどうなったか

|介入|全6ペア×4時点の平均Bridge差|各点1000 seedの一致|
|---|---:|---|
|全作用OFF|すべて0|すべてA=B|
|Aの相手系列に固定|すべて0|すべてA=B|
|Bの相手系列に固定|すべて0|すべてA=B|

これは平均で正負が打ち消し合っただけではない。各seedで差が0だった。全作用OFFでは既知ラベルを除いた実際の会話と関係状態もA/Bで一致した。

相手固定では、第三者とのBridge会話の相手・話題・反応と最終状態が、固定元の通常Aまたは通常Bと一致した。既知ペア自身の対面関係には差があり得るため、「全関係がA/Bで同じ」とは表現しない。

Aの系列へ固定したBは、Aと同じBridge結果になった。逆にBの系列へ固定したAは、Bと同じBridge結果になった。2方向から同じことを確認できたため、**今回の全6ペアで、会話相手の配分がBridge減少につながる経路を支持する証拠が強まった。**

ただし、固定したのは「各ターンに誰が誰へ話すか」の系列全体。既知ペア内会話の合計だけを固定した実験ではない。第三者からの接触やタイミング、履歴に依存する選択も含む。「既知ペア内会話数だけが唯一の媒介変数」「影響の何%がこの経路」とは同定できない。

## 4. 今回の結論として使える表現

> 本モデルの4人・全6通りの既知ペア・12〜48ターンでは、事前オンライン関係によるBridge減少に、会話相手の配分変化が関与することが介入実験で支持された。既知相手への選択優位の除去は全条件で差を縮小し、会話相手系列をA/Bで固定するとBridge差は全seedで消失した。ただし、効果量は人物組合せに依存し、選択優位の除去だけでは一部に差が残った。

「オンライン知人がいると人間の新規交流が阻害される」とは一般化しない。人工ルール内の反実仮想実験であり、異なる人数・性格・話題や、人間の実イベントでの再現は未確認。

また、この実験は前回の全因子組合せやボーナス強度スイープを他のペアで繰り返したものではない。通常、1作用ずつの除去、全部除去、2方向の相手固定という8条件に限定した。

## 次の一手

イベント設計へ進む場合、まず固定ターン数でシャッフル等が会話配分とBridgeをどう変えるかを試す根拠が整った。既知相手への集中を緩める施策が、同じ会話機会でも改善するかを直接問える。

「滞在を延ばす」効果は別である。現モデルに自発的離脱がないため、長居の効果を施策のルールへ先に埋め込まず、滞在・離脱の仕組みと根拠を別途設計する必要がある。今回、施策や滞在モデルは追加していない。

区間の方法は [NIST Bonferroni法](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm) の考え方を使う大標本正規近似。モデルの乱数に対する推定精度であり、現実の妥当性を保証する区間ではない。
