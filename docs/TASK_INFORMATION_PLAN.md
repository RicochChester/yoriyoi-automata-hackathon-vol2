# 習熟度・分散情報実験：実行前の仕様

4人、48ターン、全6既知ペア、seed101–1100、既存の共同作業弱6/中12/強24接触を継承する。
通常（familiar）と初めて（novel）をA/Bそれぞれ比較。合計72,000条件実行。
正本は現在のローカルコード、新設定task_information_v1.json、保存済み48ターン実験の共同作業記録。
既存人物・反応・関係閾値は編集しない。外部公開・課金は行わない。

通常は4情報を既知。初めては各人が1情報のみを持ち、習熟度0で開始。
4情報の話題は地域・展示・ものづくり・食。題材はイベント企画の手順を想定するが、
実際の成果物は生成しない。情報所有者はseed別に無作為割当し、A/B・強度間で共通。
既知ペアや人物の興味に合わせて所有者を選ばない。

共同作業中、話し手は相手の持つ不足情報を優先し、複数なら情報ID順で1つ質問する。
相手の持ち物を確認できる情報目録があるという仮定。相手が不足情報を持たない場合も
不足情報の先頭について質問するが、そのターンの情報取得はない。
質問のtopicを該当情報の話題へ置き換え、反応は既存のRuleResponseProviderで判定する。
相手が知っていれば返答1回で1情報を取得。好意的反応と情報提供を分離し、追加会話はない。
双方とも全文情報を知った後は通常の話題選択に戻る。ブロック間の情報リセットなし。

task_familiarity=(取得済情報数−1)/3。課題進行度は4人の習熟度平均。
完了は全員が4情報を揃えること。情報の全体和集合は最初から4なので完成指標にしない。
習熟度や課題進行度を好感度・反応点・関係評価器へ直接渡さない。
成功失敗ボーナス、個人能力、新奇性の心理効果は追加しない。

48ターンすべての話し手と相手を、Aは通常共同作業A、Bは同Bの保存記録から固定。
従ってA/B間の接触は従来どおり異なるが、通常/初めて間では完全一致する。
非作業時は不足情報の交換をしない。ただし過去の質問・反応が自然な話題に波及し得る。
相手選択に必要だった乱数1回と、元記録の話題選択の乱数消費を維持して、
情報質問が乱数列をずらすだけで反応を変えることを防ぐ。
実際の話題選択は同じ状態の乱数コピーで行う。通常条件の全会話・全状態一致を必須とする。

主対比は同seedの初めて−通常のBridge成立数/4と件数。Bを先に、A、B−A、差の差も保存。
副指標は未成立累積ターン平均、全4本成立率、既知/Bridge会話割合（固定なので差0）、
情報取得数、質問数、課題進行度、完了率、話題変更数。
全6ペアの集約はseed内で等重み平均し、1000seedを独立単位とする。
平均差の正規近似95%区間と、対比系列ごと18比較（6ペア×3強度）、
B−Aは36比較のBonferroni近似区間を保存。モデル仮定の不確実性は含まない。

必要検証：通常条件の保存基準との一致、全接触一致、質問先の所有情報からのみ取得、
情報の単調増加、初めての初期習熟度0、全員の習熟度範囲0–1、
全関係状態の既存評価器による再構築、情報のみ動かして話題接続を切った場合は関係不変。
全件の入力/出力ハッシュとCSV再集計を確認する。未完了出力は上書きせず新規実行先を使う。

これは「初めて」という心理効果そのものの実験ではない。
分散情報による必要性→指定された話題→既存の興味・反応ルールという経路を調べる。
題材・情報配置・知識共有方式に依存し、結果から人間一般の効果を断定しない。
