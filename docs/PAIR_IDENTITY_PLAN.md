# 既知ペア6通り × 会話機会：実行前計画

2026-09-11。前回のakane-midori結果は既観測。その他の結果を見る前に記録するローカル計画。
全6ペア × 12/24/36/48ターン × seed101〜1100、A/B各1回（48,000条件実行）。
既存4人の順序、性格、興味、ルール、乱数を固定。Bのonline_known_pairsとonline_experience.participantsを一致させて入れ替える。
経験は全条件で「技術について1往復」、作用の強さも固定。経験IDと条件ラベルのみ対応する名前へ変更する。
元ペアの設定は完全一致させ、前回の全4,000 A/B記録と一致確認。全ペアでAの会話と関係が同一か確認。
短い実行と長い実行の先頭一致、全時点の状態再構成、出力ハッシュ、1/4/1の分類を確認。

主指標：各ペア・各時点の共通4本のBridge成立数のseed内差B−A。親しみも成立に含む。
24個の差を一つのfamilyとして、通常95%正規近似区間とBonferroni補正した大標本正規近似同時区間を保存。
補正はz=NormalDist.inv_cdf(1−0.05/(2×24))、標準誤差はseed内差から算出する。
全24点が負でも、この4人・固定話題・固定ルールの組合せ内の頑健性に限定。区間がゼロを跨ぐ場合は方向未確定。
人物による効果量差を直接見るため、各時点の全15組のペア条件間差の差もseed対応で計算し、別family60比較として補正する。
6条件・4時点を独立6000/24000標本として扱わず、単位は1000 seedとする。前回と同じseedで新規独立追試ではない。
副指標は前回と同じ会話集中、親しみ、打ち切り付き初成立時点、未形成ターン数、全4本成立率。
既知ペアが変わると評価対象の4本も変わる。Aでの基礎的形成しやすさを差し引いた効果を比較する。
話題との適合、性格、興味、ラベル/参加者順序は今回分離しない。正の点推定だけで促進と断定しない。

元エンジン/UI/JSONは編集しない。新規実験モジュールとテスト・報告を追加。既存durationの集計と監査を再利用する。
成果物はペア別のraw traces/pairs/seed metrics、全24点のsummary、60比較のcontrasts、設定とmanifest。
