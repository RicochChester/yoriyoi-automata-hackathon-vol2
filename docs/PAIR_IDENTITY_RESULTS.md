# 既知ペア6通りの実験結果

2026-09-11。**6通りすべて、4時点すべてでBの平均Bridge数がAを下回った。一方、効果の大きさと時間による推移は人物組合せによって異なった。**

## 全24条件の結果

表は平均Bridge成立数の差B−A（最大4本）。負はBが少ないことを示す。各点1000 seed、A/B各1回。

|あかね―みどり|−0.244|−0.161|−0.121|−0.092|

**24比較を考慮したBonferroni補正の近似同時区間でも、全24点がゼロより下だった。** 平均Bridgeが増えるペア条件は今回見つからなかった。ただし、個々のseedすべてでBが不利という意味ではない。

## 「同じ方向」と「誰でも同じ効果」は違う

12ターンでは、あかね―みどりの差は−0.244、こはる―みどりは−0.120。その差の差は **−0.124件**で、60比較を考慮した近似同時区間は **[−0.183, −0.065]**。この例では、効果量の違いも乱数の揺らぎだけでは説明しにくい。

全60比較では7比較の補正区間がゼロを跨がなかった。48ターンの15比較ではゼロを跨がないものはなかったが、これは48ターンで人物差がなくなったことの証明ではない。詳細は `contrasts.csv`。これは各条件のA/B差同士を比べたもので、Bの絶対件数だけを比較したものではない。

したがって今回の結論は、**「Island方向はこの4人の全組合せで頑健。ただし、その強さは人物組合せに依存する」**となる。「誰が知り合いでもまったく同じ」とは言えない。

## 時間を増やせば一様に解決するか

全6ペアで48ターンの差の絶対値は12ターンより小さかった。ただし途中経過は単調ではない。

- こはる―みどりは−0.120 → −0.125 → −0.127 → −0.102。12から48の差の改善は+0.018で、未補正の95%区間でも[−0.012, +0.048]とゼロを跨ぐ。明確な回復とは判定できない。
- くるみ―みどりは24から36ターンで点推定の差が広がった。48ターンでも−0.137が残った。途中の拡大自体について別の検定はしていない。

成立済み関係が後退せず最大4本というモデルなので、長く観察すると天井に近づく。この効果と人物組合せの影響を混同しない。「十分長ければ全ペアでトレードオフが消える」は引き続き未確認。

## 会話集中と遅れ

48ターンでも、全6ペアで既知ペア相当への会話割合はBがAを上回った。

|既知ペア|A 会話割合|B 会話割合|48ターン内の累積未形成回数差 B−A / Bridge|
|---|---:|---:|---:|
|あかね―こはる|14.11%|19.63%|+1.304|
|あかね―みどり|12.93%|19.43%|+1.771|
|あかね―くるみ|23.43%|26.89%|+1.175|
|こはる―みどり|23.13%|26.59%|+1.251|
|こはる―くるみ|13.61%|19.72%|+1.339|
|くるみ―みどり|12.79%|19.64%|+1.822|

割合の分母は全会話数。未形成回数は各ターン終了時の未形成を数え、4本で平均した観察上限付きの記述指標。成立したペアだけを選ばず、未成立も48として含める。実時間や完全な待ち時間の平均ではない。これらの副指標には主指標24点の同時保証は適用していない。

会話集中と形成減少の並存は全ペアで見られた。ただし、前回の作用除去・会話相手固定実験を他の5ペアで繰り返したわけではないため、機序の切り分けまで全ペアで再証明したとは言わない。

## 今回強まったこと、残っていること

強まったのは、元の「あかね―みどり」だけが偶然特殊だった、という説明に対する反証である。この4人、同じ事前技術交流、既存ルール、12〜48ターンという範囲では、全組合せで平均形成数の減少方向が再現した。

今回変えたのは「同じ事前技術交流を経験した人物」。人物の性格・興味、技術話題との適合、第三者の組合せが一緒に変わるため、どれが効果量差の原因かまでは分離していない。また、新しい性格分布、人数、人間の実イベントへの一般化はできない。

次に因果経路を強めるなら、他のペアでも前回の会話相手固定・作用除去を行う。イベント設計へ進むなら、同じ会話機会でシャッフル等が配分を変える効果を先に測れる。「滞在を延ばす」研究には、別途、離脱・滞在の仕組みとその根拠が必要。今回はどちらも追加実行していない。

## 実装・成果物・検証

[方法・変更前後・PowerShell操作手順](PAIR_IDENTITY_METHOD.md) と [実行前計画](PAIR_IDENTITY_PLAN.md) を保存した。新規ファイルは `poc/ab_poc/pair_identity_experiment.py`、`tests/test_pair_identity_experiment.py`、`validation/verify_pair_identity.py`。元エンジン・UI・JSONは変更していない。

成果物は `results/pair-identity-101-1100/`。全24点のsummary、60比較のcontrasts、ペア別に全6関係のCSVと会話・全時点状態の圧縮JSONを保存した。計48,000条件実行・288,000ペア行。seedは101〜1100で前回と同一。

検証証拠は `validation/pair-identity-tests.txt`、`pair-identity-audit.json`、`pair-identity-engineering-closeout.json`。33テスト成功。全288,000ペア行の状態・成立時点を会話から再構成し一致。全24推定と60比較の再集計、A不変20,000比較、元ペアの前回4,000 A/B記録との完全一致も確認し、最終監査はpassだった。短い実行と長い実行の先頭一致も計36,000件確認した。

ローカル実験と公開準備は分ける。統合closeoutはGit追跡未登録、公開向け個人パス検査等でblocked。共有設定変更・課金・公開・pushは行っていない。追加コマンドを使わなければ通常動作に戻れる。

多重比較の方法は [NIST Bonferroni法](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm) を参照。区間は大標本正規近似で、モデルの乱数変動に対するものであり、現実の人間への不確実性を含まない。
