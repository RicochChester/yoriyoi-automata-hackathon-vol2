# 48ターン・イベント形式比較の結果

4人、全6既知ペア、seed 101〜1100、13条件、A/Bで156,000実行。数値は6ペアを等重みで集約した1000 seedの平均。Bridgeは顔見知り以上の4本を数える。これは固定48会話のモデル内比較であり、人間や滞在時間延長の効果ではない。

## 今回分かったこと

- シャッフルと共同作業の中・強条件は、全6既知ペアで自由交流Bより成立数を増やした。72比較の補正区間でも増加方向だった。Aも改善しており、Bだけに効いた施策ではない。
- 強条件のBは自由交流3.306本から、シャッフル3.641本、共同作業3.648本へ増えた。B−Aは−0.093本からそれぞれ−0.016本、−0.014本へ縮小した。平均の負の差は残っており、Island差の完全解消とは言わない。
- 紹介・強もBを3.426本へ増やし、全6既知ペアで補正後も増加方向だった。紹介したペアがその場で実際に話した割合は約42%。B−Aの差を縮める証拠はシャッフル・共同作業ほど強くない。
- 共通話題・強はBを2.355本へ減らした。Aはさらに大きく減ったため差の差だけは正になった。今回の設定では、新規形成を増やす施策として成功していない。
- 共同作業とシャッフルのB成立数差は弱・中・強のいずれも通常95%区間が0を含んだ。共同作業の方が優れている、または両者が同等であるとは確定できない。

次の検証候補は、今回改善した均等接触を維持しながら、連続配置・分散配置の開始時点も揃えた比較である。今回の結果だけから共同作業の心理的効果や、人が長く滞在する効果には進めない。共通話題の悪化原因を調べるなら、相手選択・話題内容・慎重さへの作用を個別に固定する追加実験が必要で、今回は未実施。

## 読み取りの限界と保存証拠

95%区間はseed変動についての正規近似区間。モデルの正しさ・人物設定の代表性・人間一般への推論を保証しない。多重比較補正は各対比系列ごとで、全副指標を一括した検定ではない。0を含む区間から同等性を断定しない。48ターン版は24ターン版と介入配置も違うため、過去版との差を時間延長だけの効果と呼ばない。

本体データ：results/event-formats-48-101-1100。設定・ソースハッシュはdesign.jsonとmanifest.json。各既知ペア下に全会話/状態/介入ログ、全ペアCSV、seed集計CSV。今回の補助対比：results/event-formats-48-analysis-101-1100。操作手順：EVENT_FORMAT_48_METHOD.md。全件監査：validation/event-format-48-audit.json。

## 実行・検証の完了証拠

- 本実験：156,000条件実行、936,000ペア行、全13条件×6既知ペア×1000 seedを完了。実行時間は約10分、別途全件監査を実施。
- 全件監査：全会話から関係状態を再構築し、全CSV・集計表・入力出力ハッシュの一致を確認。過去の48ターン自由交流の6,000 A/B記録とも一致。
- 回帰検証：51テスト・8追加チェック成功。過去24ターン版の保存済み108 A/B記録と一致。小規模312条件実行でも全件監査成功。
- 元の会話エンジン・反応/関係評価器・既存の人物/ルール設定は、前回イベント実験から変更なし。構文チェックも成功。
- 監査JSONのtask_shuffle_condition_matches=0は、今回は配置が異なり旧版の「結果が完全一致する」照合を適用しないという意味。失敗件数ではない。同じ配置にした別テストでは状態が一致した。
- 補助集計：主対比の再現、率＝件数/4、共同作業の成立時期4区分の合計一致を確認。

ローカル実験としては完了。共有の公開準備チェックは、Gitの追跡済みファイルがない作業コピーであることと、操作説明中のローカルパスのため未通過。このチェックのpytestは成功し、構文確認はプロジェクトのPythonで別途実施した。GitHub反映・公開は未実施で今回の対象外。人間への効果、滞在時間の自発的延長、共同作業の心理的作用、共通話題悪化の経路分解は未確認である。
