# 全既知ペアの機序実験：方法と再実行

## 比較する8条件

6ペアすべて、seed101〜1100。元の「あかね―みどり」は既存実験との照合に使い、他の5ペアに同じ介入を適用する。4人の属性と順序、事前技術交流1往復、ルール版を固定する。前回のseedを再利用しており、新規独立追試ではない。

|条件|ID|何を変えるか|
|---|---|---|
|通常|S1_R2_T1_C1|元モデルと同じ|
|選択優位を外す|S0_R2_T1_C1|既知相手を選ぶ重みの加算を0にする|
|反応優位を外す|S1_R0_T1_C1|既知相手への反応加点を0にする|
|話題記憶を外す|S1_R2_T0_C1|会話開始時の話題選択から事前記憶を隠す|
|慎重さの免除を外す|S1_R2_T1_C0|既知相手にも通常の慎重ペナルティを適用する|
|全部外す|S0_R0_T0_C0|上記4作用をすべて外す|
|Aの相手系列に固定|clamp_A|通常Aの各ターンの相手をA/B双方へ与える|
|Bの相手系列に固定|clamp_B|通常Bの各ターンの相手をA/B双方へ与える|

「全部外す」でも既知フラグそのものは記録に残る。最終の既知ペア分類のためであり、対面関係が初めから成立したことにはしない。

固定は相手の全時系列への介入である。既知ペア内の会話数だけを固定するものではなく、第三者からの接触、タイミング、過去の反応による相手選択の変化も外から決める。その上で話題と反応は条件ごとに再計算する。既存の実装が相手選択で消費する乱数1個分を空消費して、以後の乱数位置を維持する。

## モデルを変更しない実装

新規 `poc/ab_poc/pair_mechanism_experiment.py` が、前回の `Case`、`MechanismInitiator`、`MechanismResponder` を再利用する。元の `mechanism_experiment.py` の一部の実行・観察関数は「あかね―みどり・12ターン」固定なので、その関数を無理に全ペアへ流用しない。汎用の作用ラッパーをそのまま使い、設定は前回の `pair_config`、分析は前回の `extract` に委ねた。

変更前の実験呼び出しは固定ペアの `run_case(case, seed)`。変更後は新モジュールの `run_intervention(pair, seed, case, horizon, donor)` へペア・長さ・固定元を渡す。

```python
cfg = pair_config(pair, horizon)
cfg = replace(cfg, rules=replace(cfg.rules,
    selection=replace(cfg.rules.selection, online_known_bonus=float(case.selection)),
    reaction=replace(cfg.rules.reaction, online_known_bonus=case.reaction)))
```

話題と慎重さの切替、会話相手固定は前回のクラスを利用する。設定コピーなので元JSONやUIには影響しない。ドナーのseedと既知ペアが異なる場合、長さが不足する場合はエラーにする。

各条件48ターンまで実行し、`checkpoint` が12/24/36/48の状態を取り出す。取り出した時点以降の会話を集計に混ぜず、その時点のスナップショットと元の指標計算関数で集計し直す。全6ペア・全8条件・複数seedで、直接短く実行した結果と完全一致を確認した。

したがって実際の条件実行は **96,000回**、観測した条件時点は **384,000件**、全6ペアの行は **2,304,000行**。384,000回をそれぞれ独立に実行したという意味ではない。

最大2つの独立seed処理を並列に進め、保存は親プロセスのみが順番に行う。待機中の結果数を制限し、全シミュレーションをメモリに溜めない。同じseedで1プロセス・2プロセスの結果が一致するテストも実施した。

## 指標と推論の範囲

主指標は、Bの既知ペアから第三者への4本について、顔見知り以上の成立数B−A。人物・seed・時点が同じA/Bを対応させる。

各介入のB−Aに加え、介入のB−Aから通常のB−Aを引いた「介入による差の変化」を計算する。正なら元の負の差を縮める方向。ただし、相手系列を固定した結果と自然な世界は別の介入世界であり、現実の政策効果をそのまま表すものではない。

192条件の平均差を一family、168の対比を別familyとして、Bonferroni補正の近似同時区間を保存する。通常区間は平均±1.96標準誤差、補正係数は標準正規分布の分位点。標準誤差はseed内差から計算する。副指標にこの同時保証を転用せず、複数familyを合わせた厳密95%保証とも呼ばない。[NISTの多重区間の考え方](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm) を参照。有限標本の厳密保証ではなく、大標本正規近似である。

全作用を外したときのA/B一致と、相手固定時のBridge記録一致は、標本平均の検定だけでなく全seedの不変条件として確認する。差がゼロで標準誤差もゼロなら区間も[0,0]になるが、有限な試行とこのルールでの一致を、人間や別モデルの普遍的ゼロ効果と解釈しない。

1作用ずつの除去は通常状態を背景にした比較。全因子実験のような相互作用の網羅、各経路の寄与率、唯一の媒介経路は同定していない。

## 保存と監査

正規成果物は `results/pair-mechanism-101-1100/`。

- `summary.csv/json`：192条件の平均・区間・会話配分等。
- `contrasts.csv/json`：168の「介入−通常」対比。
- `design.json`：基準設定、8条件の定義、seed、ソース指紋。
- 各ペア名フォルダの `traces.jsonl.gz`：8条件×1000 seedの実際の48ターン会話と全状態。
- 同フォルダの `pairs.csv`：4時点の全6ペア。既知ペア、case、seed、turns、分類、最終状態、初成立時点、打ち切りを含む。
- `seed_metrics.csv`：対応差と副指標。`complete.json`：ペア単位の保存完了と指紋。
- 最上位 `manifest.json`：全実験の完了とファイル指紋。

正本は現在のローカルソースと保存設定・SHA-256。元GitHub取得revisionは `1cc02b28f850b2843c464f91146fd6b89c34f9a9`。Git追跡未登録のため、今回の追加処理をそのGitHubコミットに含まれると表現しない。

`validation/verify_pair_mechanism.py` は全48ターンの関係を会話イベントから再構成し、全時点CSV・全集計と照合する。通常条件は前回のペア変更実験の24,000 A/B時点と、元ペア12ターンは前回の機序実験の8,000 A/B条件と照合する。全作用0・固定の不変条件も再確認する。

監査処理の初回実行で指紋関数の読み込み漏れが発生した。監査コードのみを修正し、監査全体を小規模データで実行する回帰テストを追加してから再開した。実験の行動ルールや保存データは変更していない。

## PowerShellで再実行

プロジェクトへ移動する。

```powershell
Set-Location "<cloneしたリポジトリのフォルダ>"
```

少数seedで動作確認する。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m poc.ab_poc.pair_mechanism_experiment --seed-start 101 --seed-end 103
```

全実験を再実行する。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m poc.ab_poc.pair_mechanism_experiment
```

今回の保存済み本実験を監査する。

```powershell
.\.venv\Scripts\python.exe -X utf8 validation/verify_pair_mechanism.py
```

PC負荷を下げるには実験コマンドに `--workers 1` を付ける。出力先省略時は時刻付きの新しいフォルダを作り、既存出力を上書きしない。APIキー・追加パッケージ不要。今回Windowsの既存venvで確認した。

エラー時は表示文と保存先を保管する。最上位manifestがないフォルダを全実験完了と扱わない。再試行は新しい出力先へ行う。無効化は追加実験コマンドを使わないだけでよく、元のモデルの復元は不要。保守・成果物の所有先はこのローカルYoriyoiプロジェクト。
