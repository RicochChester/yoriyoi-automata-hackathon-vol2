# 会話機会を増やす実験 v1：実行前計画

2026-09-11。12ターンのseed 101〜1100は既観測で平均Bridge差−0.244。
24・36・48ターンの結果を見る前に記録。ローカル事前計画であり公開事前登録ではない。

目的：同じ4人・同じ既知ペア・同じ選択／反応／関係判定ルールで、会話機会だけを増やした場合、BのBridge成立数が増え、A/B差が縮むか。
既知ペア変更、人数変更、イベント施策、滞在・離脱ルール、LLM、人間への実験は対象外。

条件は12・24・36・48ターン。各条件に同一のseed 101〜1100を使用し、A/B各1実行。
計4000 A/B組＝8000条件実行。短い実行が長い実行の先頭部分と一致することを全seedで確認する。
前回と同じseedを使うため、新規独立1000 seedによる検証とは呼ばない。

変更は読み込んだ設定オブジェクトのrules.turnsのみ。元のJSON loaderの12ターン制約は維持。
実験用のdataclassコピーを既存run_abへ渡し、通常UIやエンジンは変更しない。

主指標：各長さのBridge成立数A/B、対応差B−A、率（分母4）。
主対比：48ターンの差−12ターンの差（seed内の差の差）。正の値は負の差が回復する方向を表すが、符号反転時は絶対値も確認。
24・36ターンは推移の記述。単調に縮むことを前提にせず、差が途中で広がる結果も報告する。

副指標：親しみのあるBridge数、共通5ペア、既知ペア内会話の割合、端点から第三者への発話数、全Bridge4ペア成立の頻度。
形成時刻：各ペアの最初の顔見知り・親しみのturn。終了まで未形成はnull＋打切りフラグとし、0や終了turnに置き換えない。
遅れ：各Bridgeペアの「turn終了時点で未形成だった回数」を合計し4で割った平均未形成ターン数。未形成ペアも含む。形成したペアだけの平均待ち時間は使わない。
終了時の差の縮小と、それ以前に発生した形成の遅れの解消を区別する。

区間は前回のestimate()を再利用し、対応差の平均±1.96×標準誤差の近似95%モンテカルロ区間。
1000 seedを標本単位とし、辺や長さを独立標本に数えない。近似区間が0を含むだけで「差なし」「同等」「トレードオフ解消」とは判定しない。
実用上無視できる差の閾値は未合意なので、同等性判定は行わず効果量を報告する。

反証・制約：差が縮まらなければ回復仮説はこの範囲で未支持。両条件が4件の上限へ近づく場合は天井効果を併記。
関係が後退しない累積型モデルなので、絶対件数が増えることだけは仮説の強い証拠にならない。
ターンは分・時間に対応せず、48ターンを実際の「十分な滞在時間」と呼ばない。
②滞在を延ばす施策、③その施策のBridge効果は、参加者の離脱や滞在を表す機構・データが必要であり今回の結果から直接確定しない。

保存：使用設定・計画・ソースの照合値、全ペアCSV、seed別CSV、要約CSV/JSON、会話とsnapshotを保持する圧縮ログ、最後に完了manifest。
既存出力は上書きしない。実行中にソース・計画が変わった場合は完了と扱わない。
検証：既存23テスト維持、12ターンの前回データ一致、全長さのprefix一致、設定差がturnsだけ、保存ログから関係判定器で再構成、CSV/JSON再集計一致。

方法の根拠：[ABM出力解析のレビュー](https://www.jasss.org/18/4/4.html)、[NIST平均の信頼区間](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)。前回と同じ近似区間と実行基盤を再利用し、新しい統計ライブラリは追加しない。
