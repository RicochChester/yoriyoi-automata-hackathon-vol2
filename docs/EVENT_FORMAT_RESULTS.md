# イベント形式によってBridge形成はどう変わるか

**このモデルでは、強いペアシャッフル／単純な共同作業がBのBridge形成を増やした。一方、弱いシャッフル／共同作業、今回のホスト紹介、共通話題条件は、6ペア平均では自由交流より形成数を減らした。**

24ターン・4人・全6既知ペア・seed101〜1100。自由交流1条件と4施策×弱強の計9条件を実行。実際の条件実行108,000回、全ペア648,000行。結果はこの人物設定・ルール・介入位置に限定される。

**差が縮んでも、イベントの形成数が改善したとは限らない。** 例えば共通話題強ではBが−0.662件、Aが−0.729件と両方悪化し、Aの減少が大きい結果として差が縮んだ。弱いシャッフルや紹介でも同じ注意が必要。

強いシャッフル／共同作業は、Bの形成数の増加とIsland差の縮小を同時に満たした。差の縮小は+0.1212件で、補正区間は[+0.0934, +0.1489]。残ったB−Aは−0.0035件、通常区間[−0.0106, +0.0036]、補正区間[−0.0156, +0.0086]。ゼロに近いが、等価性の許容幅を設定していないため「完全に解消した」とは判定しない。

紹介弱のIsland対比は通常区間では正側だが、補正区間[−0.0136, +0.0583]はゼロを跨ぐ。補正前だけを採用して効果を強く見せない。

## 4. 施策固有の記録から分かること

### シャッフル

強制接触の直前に会話回数が2未満だった割合はBで弱52.65%、強58.30%。「接触不足」は元の顔見知り会話回数閾値2を参照しており、肯定的反応の有無まで含む充足判定ではない。

弱は各ペアを1回、強は2回使う。元の関係成立には複数回の会話が必要なので、接触を広げることと、成立に足りる反復を確保することは別である。この違いは弱強の逆方向の結果と整合するが、唯一の原因として切り分けたわけではない。話し手変更・介入時期・方向も施策の一部。

### 単純な共同作業

今回、シャッフルと共同作業は同じペア計画である。共同作業では「情報を渡す」「作業結果を確認する」「次の工程へつなぐ」という課題役割と発話意図を付けるが、これを新しい反応加点にしない。元の評価器は文言から関係点を加えないため、全seedで会話の相手・話題・反応・関係状態が一致した。

**今回は、共同作業固有の心理的効果を測った実験ではない。** 共同課題によって指定相手への接触が生じる単純な構造を表したもの。同値になることは実行前に記録し、数値差を作る追加ルールは入れていない。

Bの平均Bridge初成立を時期別に分けると：

|共同作業|最初の課題前|課題ターン中|課題と課題の合間|最後の課題終了後|
|---|---:|---:|---:|---:|
|弱|0.175|0.793|1.506|0|
|強|0.000|2.008|1.044|0|

最終課題は24ターンなので、その後の観察期間はない。合間の形成をすべて課題の因果効果とは扱わない。上表は保存済み初成立時点から追加した記述集計で、計画段階の主比較を変更していない。

### ホスト紹介

紹介bonusは既存の選択加点と同じ1.0。弱強で固定。紹介が同じターンの実会話につながった割合はBで弱42.63%、強42.75%。強制接触ではないので、紹介しても別の相手に話す場合がある。

最少会話ペアを選ぶ処理自体は全件で確認した。今回の減少を「紹介一般は悪い」とは言えない。bonus1.0、指定時点、話し手の交代、既存の反応・関係閾値を組み合わせた結果である。

### 共通話題

介入中の共有興味判定は真だが、全員の個人興味や `topic_match` を真にしたわけではない。元の共通話題やオンライン記憶の優先順位、興味との一致に基づく反応が残る。

また、自由交流の発話順を維持するこの形式では、弱の介入ターンを担当する話し手は1人、強は2人に限られる。seedによって担当人物は変わる。「全員が同時に話題提供を受けて会話する交流会」ではない。

接触配分や使われる話題を変えることで、元々形成しやすかった交流が置き換わる可能性がある。ただし、そのどれが減少の原因かを分離する追加介入はしていない。今回の結果を人間の共通話題提示の評価へ直結させない。

## 5. 再現性と変更内容

[方法・変更前後・PowerShell手順](EVENT_FORMAT_METHOD.md)、[実行前計画](EVENT_FORMAT_PLAN.md) を保存した。

必要な既存変更は `engine.py` の任意の話し手指定、`rule_providers.py` の共有興味判定の差替え入口、`bridge_experiment.py` の実発話順が分かれる場合の明示対応。新規 `event_format_experiment.py` と `event_formats_v1.json` が9条件を定義する。人物・A/Bの事前交流・関係形成閾値は変更していない。

## 次に検証するなら

今回の有望条件は「24ターン中12回、全6ペアを2回ずつ指定する」構造。ただし、形成の早さも改善したとは言えない。

次は接触回数を同じに保って時期や話し手配分を変え、早期形成も改善するかを切り分けられる。共同作業の固有効果を調べるには、何を行動上の違いとして追加するかと、その根拠を別途定義する必要がある。今回は新奇性、技能、滞在延長、人間への効果は検証していない。
