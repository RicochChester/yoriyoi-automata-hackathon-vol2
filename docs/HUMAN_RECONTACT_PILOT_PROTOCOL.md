# 人を対象とする4条件比較：予備調査の実施案

**状態: 未実施。観察データなし。以下は実施案と空の記録票であり、実験結果ではない。** 募集・参加者への連絡・録画・外部サービスへの登録は行っていない。

## 目的

手順の未経験と、他者の情報を必要とする構造を分け、共同作業後の自発的な再接触を観察する。
現モデルの係数を人間の実測値と扱わない。まず観察可能な行動を定義し、実施可能性と記録の精度を確認する。

## 4条件と、分けるべき2種類の知識

|条件ID|手順への慣れ|今回の課題の情報|
|---|---|---|
|F_I|事前練習あり|各自が必要情報を全て持つ|
|N_I|事前練習なし|各自が必要情報を全て持つ|
|F_D|事前練習あり|必要情報を4人に分散させる|
|N_D|事前練習なし|必要情報を4人に分散させる|

慣れているのは「手順」であり、本番の答えや他人の情報ではない。練習には別の課題インスタンスを使う。これによりF_Dでも他者への確認が必要になる。
既存シミュレータの情報保有量だけでは、この2要因を独立に表現できない。4条件をラベルだけでコード化して新奇性効果を主張しない。

題材の候補は、図形やカードをルールに従って配置する小課題。題材・ルール・難易度は予備確認後に固定し、task_versionを付ける。慣れた条件の手順理解と、初めて条件でも最低限取り組めることを確認する。
成果物は全条件で同じ形式にする。4人それぞれが同じ形式の小課題を提出し、最後に同じ手順で並べる。個人完結条件では必要な情報を各自が持ち、相互依存条件では他者から受け取らなければ自分の小課題を完成できないようにする。共同成果物を作る条件だけ特別な評価や報酬を与えない。接触枠は同じだが、情報を必要とするかが異なる。

## 実施の流れ（時間は予備案）

1. 参加・記録方法の説明と同意。匿名IDを割り当て、以前からのオンライン/対面関係を確認する。
2. 題材への興味、課題経験、開始前の負担感を記録する。練習あり条件は個人練習、なし条件は同じ時間の中立的な個人活動とする。事前の参加者間交流を増やさない。
3. 共同作業12分。2分×6枠で、各枠に2組が同時に交流する。全6ペアが各2回接触する。
4. 同じ10分の自由交流。相手は指定せず、会話の開始・終了、誰から誰への接触かを記録する。
5. 課題への慣れ、他者の必要性、負担感、再度話したい相手を本人に尋ねる。再交流希望の質問は自由交流後に行い、先に意識させない。

接触枠の基本形: (P1-P2/P3-P4)、(P1-P3/P2-P4)、(P1-P4/P2-P3)を2巡。順序は事前に割り当て、4条件で均等化する。情報の他ペアへの漏れや、予定外の会話は記録する。
人では2組同時、現モデルでは1ターン1会話である。12分と12ターンを同一視しない。
人の興味一致や好反応確率を完全に固定することはできない。題材と接触枠を揃え、違いを測定する。条件間の違いがないことを事前に保証したと報告しない。

## 割り当てと必要人数

4人のグループ単位で4条件へ無作為に割り当てる。同じ人が複数条件を経験する設計は、慣れや既知関係が残るため初回は使わない。割り当て方法と乱数seedを開始前に保存する。
既知関係を含める場合は、既知関係の構成が4条件に偏らないよう事前に層を分ける。最初の予備調査では既知関係の有無まで追加要因にせず、対象条件を揃える。
必要人数は未確定。少数グループの動作確認結果から効果の有無を断定しない。予備調査で得たグループ間のばらつきと、検出したい最小差を使って本調査の人数を別途決める。

## 観察するもの

主な行動指標:
- 自由交流で、課題中に情報を受け取った相手へ自分から接触した割合。
- その時点で選べる相手のうち情報提供者が何人いたか。単純な接触割合と併記する。
- 既知相手/第三者への接触割合、新しく会話した異なるペア数。
- 会話の継続時間。打ち切りや観察不能を区別する。

全員が全ペアと課題中に接触するので、自由交流を「初めて接触したか」だけでは評価できない。
情報提供者がいない人の「提供者への再接触率」は、意味のある分母を持たないため欠測/該当なしとする。自動的に0へ置換して条件差を作らない。
シミュレータの「2会話以上・好反応1回以上」を、そのまま人の関係成立の測定値にはしない。行動と本人評価を別に記録し、Bridge成立の実測定義は本調査前に決める。
自然な離脱や任意延長は今回の固定10分だけでは評価できない。滞在時間の延長効果は別実験で扱う。

## 記録票

`study_materials/recontact_pilot/` のCSVはヘッダーのみで、架空の参加者や結果は入っていない。

- sessions.csv: グループ/条件/時間/課題版/割り当てseed/逸脱。
- participants.csv: 匿名ID、事前興味・経験、事後の慣れ/依存感/負担感。
- prior_pairs.csv: 事前のオンライン/対面関係。人名は記録しない。
- conversations.csv: 接触の開始/終了、話しかけた側、相手、選択可能だった相手、指定接触か、観察状態。
- information_events.csv: 誰から誰へ、どの課題情報が渡ったか。
- recontact_preferences.csv: 自由交流後、各相手と再度話したい度合い。

時刻は自由交流開始を0とする秒（課題中は負値）。参加者IDは同じグループ内のP1～P4、複数候補はセミコロン区切り。
1対1以外の交流はinteraction_type=groupとし、membersに参加者IDを列挙する。分析から黙って除かず、別に集計する。分からない話し手・欠測・打ち切りはobservation_statusに記録する。
本人評価は1～5（低い～高い）を仮の共通尺度とし、質問文と尺度の版を実施前に固定する。回答を機械的にモデルの関係点へ換算しない。

## 分析と次の判断

最初は実施可能性、記録漏れ、条件操作が成立したかを確認する。その後、グループを単位として条件差と区間を推定する。参加者や会話をすべて独立サンプルと扱わない。
「新奇性」「相互依存」と両者の組み合わせを分けて見る。情報交換の発生自体は無作為ではないため、提供者への再接触との相関だけを因果効果とは呼ばない。
モデルへ反映する場合は、係数調整用と検証用のグループを分ける。次のグループでも再現できるかを見る。
実施責任者・場所・参加者・課題教材・同意/記録方法・人数は人間側の未決事項。確定後に予備調査を行い、保存記録をAIが集計する。現在は結果未取得。
