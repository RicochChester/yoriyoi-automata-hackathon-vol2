# 全既知ペアの作用除去・会話相手固定：実行前計画

2026-09-11。全6ペア、seed101〜1100、12/24/36/48ターン。元ペアは整合性対照、他5ペアが新しい機序検証。
8条件：通常S1_R2_T1_C1、Sのみ0、Rのみ0、Tのみ0、Cのみ0、全作用0、clamp_A、clamp_B。
S=既知相手選択bonus、R=反応bonus、T=事前話題記憶、C=既知相手での慎重ペナルティ免除。
前回のCase/MechanismInitiator/MechanismResponderを再利用。通常の設定・モデルファイルは編集しない。
既知フラグと技術1往復の記憶は各ペアへ一緒に移す。全作用0でも既知という記録ラベル自体は残す。
固定はそのペア・seedの通常Aまたは通常Bの各ターンの相手IDを、A/B双方へ外から与える。既知ペア内会話数だけを固定する介入ではない。
相手選択が消費した乱数1個分を維持し、話題・反応は各条件内で再計算する。

各条件48ターンを実行し、保存したturn_endから12/24/36/48の状態を読み取る。96,000条件実行、384,000条件時点、2,304,000ペア行。
直接短く実行した結果との一致を全ペア・全条件・複数seedで先行テストする。履歴を改変して先頭を揃えるのではない。
同一seedで対応させ、24時点条件を独立標本として扱わない。前回seed再利用で新規独立追試ではない。
通常結果は前回の全ペア全時点データと照合。元ペア12ターンの8条件は前回機序実験と照合する。

主指標：各ペア×4時点×8条件のBridge差B−A（共通4本、親しみを含む成立）。192区間を一familyとしてBonferroni正規近似区間を追加。
主対比：7介入の差−通常の差をseed内計算（6×4×7=168区間、別family）。通常95%区間と補正区間を保存する。
副指標：既知ペア内会話、既知者から第三者への発話、全Bridge成立率、親しみ、観察上限付き未形成回数。
全作用0ではA/Bの実会話と既知ラベルを除いた関係状態が一致するか、固定ではBridgeの会話・反応・関係がドナーと一致するかを全seed検査。
固定で差0の場合も、唯一の媒介経路・人間への因果効果とは呼ばない。固定したのは会話相手の全系列であり、時期や第三者からの接触も含む。
作用除去は通常状態で1つを外した対比で、全因子組合せ実験ではない。相互作用の網羅・個別媒介割合の同定は対象外。
C作用を受ける慎重な人物がいないペアではC除去が無作用になる可能性をあらかじめ認める。

保存：全48ターンの圧縮会話・全状態、時点別全ペアCSV/seed指標、設定・ソースhash・manifest、192集計と168対比。
検証：既存テスト、直接短期run一致、前回記録一致、全状態を会話から再構成、作用除去と固定の不変条件、欠損・重複・CSV/JSON/hash。
失敗時の部分出力は完了扱いしない。新しいフォルダのみ使用。少数の独立seed処理は最大2プロセスで実行可能、共有ファイルへ同時書込みしない。
課金、API、公開、共有設定変更、削除なし。方法参照：[NIST Bonferroni](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm)。有限標本の厳密保証ではない。
