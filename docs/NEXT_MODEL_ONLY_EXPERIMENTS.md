# 人の予備実験を使わない追加検証案

2026年9月15日作成。設計案であり、以下の実験は未実行。既存ソース、人物、A/B条件、反応式、関係閾値を維持し、モデル内で成り立つ条件と作用経路を調べる。人への妥当性や実際の滞在時間を推定したとは扱わない。

## 優先する実験

共同作業を初期の6会話で行い、その後の情報提供者への再接触を比較する。前回は課題終了時にBのBridgeが平均3.6485/4本成立しており、追加形成の余地が小さかった。今回は、各ペアが1回ずつ接触した段階から再接触の違いを見る。

前回との違いには課題量・情報取得量・介入開始時点も含まれる。新条件で差が出ても、前回の小さな差の原因が天井効果だけだったと断定しない。

### 固定条件

- 4人、全6既知ペア、Aはオンライン既知関係なし、Bは1組あり。
- 第1〜6ターンは全6無向ペアを1回ずつ使う共同作業。1ターン1会話。介入時の話し手変更は既承認。
- 相手の順序と話し手方向はseedごとに決め、A/Bと全比較条件で一致させる。既知ペアやBridgeを優先しない。
- 情報は各人1つから開始し、既存の移転ルールを使う。情報から話題への接続は無効にし、課題部分の会話・反応・関係状態を全比較条件で一致させる。
- 第7〜48ターンは自由交流。再接触への作用は第7ターンから有効にし、情報提供履歴は第6ターン終了時に固定する。
- 既存の成立閾値では、6ターン終了時は全ペア1接触なのでBridge成立数は0になる。これをスモークで確認する。
- 本実験候補seedは1101〜2100。既存記録との重複を実装前に確認し、使用済みなら別の未使用連続1000 seedへ変更して実行前に記録する。実装確認には旧seedを使用する。新seedでも現実への外部検証とはならない。

### 5比較条件

|条件|自由交流の相手選択|
|---|---|
|中立|通常ルール|
|実際の情報提供者を促進|実際の受領情報数に応じて選択重みを上げる|
|実際の情報提供者を抑制|実際の受領情報数に応じて選択重みを下げる|
|提供者ラベルを入れ替えて促進|同じ倍率の組を、別の候補への重みとして使う|
|提供者ラベルを入れ替えて抑制|同じ倍率の組を、別の候補への重みとして使う|

倍率は前回の式 `2 ** (theta * c / 3)` を維持し、thetaは−1、0、+1。cはその相手から受け取った異なる情報数。新しい関係加点・好反応加点は追加しない。最大倍率は重みの半分/2倍であり、確率自体の半分/2倍ではない。

ラベル入れ替えでは、各話し手について候補3人に対応するcのベクトルをseedで並べ替える。実際の情報・会話履歴を書き換えず、選択重みに使うラベルのみ変更する。入れ替えは後半を通じて固定し、同じseedのA/Bで同じ写像を使う。同値の要素や元と同じ並びも許し、その割合を記録する。変化の出る並びだけ選ばない。

この対照は「情報をくれた人物との対応が重要か」を見るもの。同じ倍率の集合でも各候補の元の重みが違うため、実際の選択確率の変化量まで完全には一致しない。候補分布の変化量を併記し、万能の心理的な対照とは解釈しない。

### 観測と判断

主評価時点は計24ターン。計12・48ターンは副評価。最長48ターンの1実行から途中の状態を取得し、別々の実行で世界を引き直さない。

5条件×6既知ペア×1000 seed×A/Bで60,000条件実行。3時点を別試行として水増ししない。

主指標はBridge成立数/4。Bの各条件−中立を先に評価し、Aの変化、B−Aとその変化を併記する。さらに実際の提供者を使う条件−ラベル入れ替え条件を比較する。

副指標は未成立累積ターン、全4本成立率、既知ペア/Bridge候補への会話割合、情報提供者への再接触割合、まだBridge未成立の相手への会話数。操作確認として候補別の重み・正規化後の確率・情報受領量・入れ替え有無を保存する。過程の選択で群を分けた分析は説明用とし、因果的な部分集団効果と呼ばない。

同一seedの対応差を使い、6ペア集約はseed内平均後に区間を計算する。95% Monte Carlo区間に加え、主評価時点のBについて、4条件対中立と実際対入れ替え2対比の計6対比×6ペア=36対比を1系列とする補正区間を保存する。Aと他時点・副指標の探索結果を、この同時保証に含めたとは主張しない。

結果は改善・悪化・方向不明のいずれもそのまま報告する。「効果なし」を主張するための実用上の許容差はまだ決めていないので、ゼロを含む区間を同等性の証明とは呼ばない。

### 受け入れ検証

課題6ターンの全条件一致、全6ペアの各1接触、課題終了時Bridge 0、初期世界のA/B整合、theta=0と通常ルール一致、情報授受なしで全条件一致、ラベル入れ替え前後で倍率集合一致、関係への直接加点なし、保存後の全会話・反応・関係状態再構築を確認する。新seedと新しい課題配置を扱う最小の実験ラッパーを追加し、通常UIは変えない。

## 次の段階として有用な実験

### 接触を配る時期

均等接触の効果をイベントの設計へ結びつけるため、同じ48ターン・同じ6介入で、序盤集中1〜6、中盤集中22〜27、終盤集中43〜48、分散8・15・22・29・36・43を比較する。自由交流も基準に置く。全ペア各1回、同じペア順、話し手方向、人物・関係ルールを維持する。形式はまずペアシャッフル1種類に絞り、再接触係数を追加しない。

これで調べるのは「いつ接触を配ると、形成数や形成の早さが改善するか」。共同作業の心理効果や人の滞在延長ではない。介入後の残り時間が違うことは、このタイミング施策の一部として扱う。計48ターンの最終成立数と、全期間の形成の遅れを併読する。

### 結果が人物設定に依存する範囲

前段の主要比較が固まってから、興味の重なりや慎重さなどを一要因ずつ変える。現在の4人を既知ペア6通りに分けただけでは、性格の一般性は確認できていない。成功条件だけを拾わず、差が反転する条件も記録する。人数・性格・関係閾値・滞在ルールを一度に変更しない。人物設定を変える段階は別計画として明示する。

## 今回は見送るもの

人の観察を前提とする作業は本計画から外す。感謝・達成感・新奇性への直接加点は追加しない。人が退出する判断の実測根拠がないため、現時点で離脱モデルを作って実際の滞在延長への回答とすることも避ける。

4つの問いのうち、①会話機会と②イベント構造へのモデル内の回答を深める計画である。③実際の滞在を延ばす要因と④実際の滞在延長を通じたBridge増加は未確認のまま残る。将来仮定の離脱ルールを比較する場合も、ルールごとの結果として報告する。

モデルの仕組み・変更点・仮定・感度分析の記述は、ODDの実験記述の考え方を参考にする。具体的な条件と数値は本プロジェクトの設計案であり、引用文献が実証した値ではない。
