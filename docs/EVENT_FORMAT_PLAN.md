# イベント形式比較：実行前計画

ユーザー承認済み：介入時だけ話し手も変更可能。非介入時は元の順序、自由交流は完全に元の動作。
4人・24ターン・seed101〜1100・全6既知ペア。自由交流1＋4形式×弱強＝9条件、計108,000条件実行。
弱4,8,12,16,20,24、強2,4,...,24。人数・興味・慎重さ・関係閾値・事前技術1往復を固定。
通常はseedで並べた4人の順序を反復するため、介入位置と全6ペア均等を両立するには話し手変更が必要。
話し手の回数配分も変わる施策として解釈し、全員の実発話開始回数を保存する。

シャッフル：弱は全6ペア各1回、強は各2回。seed専用の事前シャッフルで順序決定。強は同じ順序を2周、2周目は発話方向を反転。ペア抽出・方向に既知フラグを使わない。
共同作業：シャッフルと同じ接触系列。情報受け渡し・確認・次工程引継ぎのtask_roleとapproachを記録。話題・反応・関係判定は元のまま。作業能力等なし。今回は意味づけだけなので両形式の数値は同じになるという実装上の予測を事前記録する。
ホスト：全6ペアの過去会話数の最小を選ぶ。同点は(seed,turn,host-tie)の別乱数で決定。選んだペアの一人を(seed,turn,host-direction)で話し手にする。相手には選択bonus1.0を追加し、既存の反復相手倍率より前に加算。強弱は回数のみ変更。必ず会話するとは限らない。A/B履歴が異なれば紹介先も異なる。
共通話題：介入中だけ共有興味判定を全ペアで真にする。既存共有話題があれば維持、なければrules.common_topicを共有話題として返す。既存のオンライン記憶優先順位は維持。選択・話題選択・慎重ペナルティ免除に反映し、topic_match判定や個人興味は改変しない。非介入時には解除。
介入用乱数は通常会話乱数から分離。強制選択時も通常の相手選択で消費するrandom()を1つ消費する。

主指標：共通Bridge4本の成立数/4。A平均件数・率、B平均件数・率、B−A、B施策−B自由、(B−A)施策−(B−A)自由。A施策−A自由も保存。
比較順序：まずB改善、次にIsland差の変化。差の縮小だけを成功と呼ばず、Aが悪化した可能性も見る。
同一seed内で対応差を計算。各ペア×8施策の48比較について、B改善、A改善、Island対比を各別familyとしてBonferroni正規近似同時区間を保存。B−Aは54条件family。通常95%区間も併記。
全ペア平均はseed内で6条件を等重み平均してから推定。6000独立seedとはしない。副指標の区間は記述的、主family保証を転用しない。
副指標：累積未形成ターン/Bridge、既知ペア会話割合、Bridge会話割合、全4本成立割合。
補助指標：強制接触前の会話回数が既存顔見知り会話閾値2未満の割合、課題中/非課題中の新規Bridge成立、紹介が同ターンに実現した割合、話題介入中の初接触Bridge会話と新規成立。
共同作業「後」は次の介入までを含む非課題ターンで別記し、最終課題は24ターンなので最終課題終了後の追跡は0ターン。

検証：通常結果を前回全ペア24ターン6000 A/B記録と一致確認。介入位置・接触均等・履歴最少・bonus・共有判定解除・A/B共通計画・共同作業シャッフル同値を検査。全状態を保存会話から再構成、CSV/JSON再集計、設定・指紋確認。
元ソースの必要3ファイルは変更前コピーをvalidation/event-source-beforeに保存し、差分を残す。UI/既存通常動作を回帰テストする。課金・公開・外部API・削除なし。
結果にはモデル内に限定した解釈、数値同値の形式、発話回数配分変更、48ターン等の過去出力は旧ソースhashに結び付くことを明記する。
