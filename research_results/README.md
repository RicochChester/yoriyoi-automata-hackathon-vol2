# 追加実験の公開用集計

このフォルダは、完了済みのローカル実験からコピーした集計CSVと元の設計・manifestです。`index.json`に収録ファイルのSHA-256を記録しています。元のデータは変更していません。

全seedの会話・関係状態を含む大容量の生ログは、このPRには含めていません。コードと各実験の手順から`results/`へ再生成できます。`tests/fixtures/`は検証済み記録から切り出したseed 101（v1回帰は101〜102）の小さなテストデータで、本実験全体の代わりではありません。

元のmanifestは「実験当時のローカル成果物」のハッシュです。その`output_sha256`が指す全ファイルがこのフォルダにあるわけではありません。また公開時にドキュメントの個人パス除去やテストの移植を行っているため、当時の`source_sha256`と現在のcheckoutをそのまま照合するものではありません。新たに実行すると、そのcheckoutのソースハッシュと新しい出力manifestが生成されます。

これらはすべて人工モデルの出力です。人の観察データは含まれていません。

実験一覧・再現順序は[実験ガイド](../docs/EXPERIMENTS.md)を参照してください。
